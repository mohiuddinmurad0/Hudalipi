# Hudalipi

A responsive Bengali website for the Hudalipi Islamic YouTube channel, featuring the channel identity, learning topics, FAQs, and YouTube links.

## Preview locally

No dependency installation or build step is required.

```sh
python3 -m http.server 5173 --directory dist
```

Open http://localhost:5173 in your browser.

## Files

- `dist/index.html` — page structure and Bengali content
- `dist/style.css` — responsive styles
- `dist/app.js` — topic selection and mobile navigation
- `dist/assets/` — channel logo and banner
- `.openai/hosting.json` — existing Sites deployment configuration

Channel: https://www.youtube.com/@hudalipi
